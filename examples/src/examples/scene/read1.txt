用PlayCanvas做一个“车间火灾应急演练”场景，通常会分为 **场景建模 → 火焰烟雾特效 → 报警系统 → 联动逻辑 → 可视化展示** 五个部分。

## 整体架构

```text
车间场景(GLB)
│
├── 着火点(Fire Point)
│   ├── 火焰粒子
│   ├── 烟雾粒子
│   ├── 热浪效果
│   └── 火势等级
│
├── 报警系统
│   ├── 烟感器
│   ├── 温感器
│   ├── 声光报警器
│   └── 消防广播
│
├── 联动控制
│   ├── 火势蔓延
│   ├── 报警触发
│   ├── 喷淋系统
│   └── 应急照明
│
└── 数据面板
    ├── 温度
    ├── 烟雾浓度
    ├── 报警状态
    └── 逃生路径
```

# 2. 火焰效果

PlayCanvas 自带 Particle System。

```javascript

fire.addComponent("particlesystem", {
    numParticles: 300,
    lifetime: 2,
    rate: 0.02,
    emitterShape: pc.EMITTERSHAPE_SPHERE
});
```

# 3. 烟雾效果

烟雾实际上比火焰更重要。

火灾模拟：

```javascript
const smoke = new pc.Entity();

smoke.addComponent("particlesystem", {
    numParticles: 1000,
    lifetime: 8,
    rate: 0.01
});
```

参数：

```text
颜色：
黑色 → 灰色 → 透明

尺寸：
0.5 → 5m

速度：
向上漂浮
```

推荐采用：

```text
GPU Particles
```

否则几千个粒子性能下降明显。

# 5. 报警器

建立实体：

```javascript
Alarm
```

包含：

```text
红色警灯
蜂鸣器
```

### 灯光闪烁

```javascript
this.time += dt;

const v = Math.sin(this.time * 20);

this.entity.light.intensity =
    v > 0 ? 5 : 0;
```

---

### 警报声音

导入：

```text
alarm.mp3
```

播放：

```javascript
alarm.sound.play('alarm');
```

# 6. 烟感器检测

建立多个传感器：

```javascript
SmokeSensor_01
SmokeSensor_02
SmokeSensor_03
```

逻辑：

```javascript
distance < 5m
```

或者：

```javascript
smokeDensity > threshold
```

触发：

```javascript
Alarm.Start();
```

# 7. 火势蔓延

定义：

```javascript
class FireNode
{
    position;
    level;
}
```

火势等级：

```text
0 无火
1 小火
2 中火
3 大火
```

传播：

```javascript
if (distance < 3)
{
    target.level++;
}
```

形成：

```text
A
↓
B
↓
C
↓
D
```

逐步扩散。

# 8. 喷淋系统

天花板：

```text
Sprinkler_01
Sprinkler_02
```

触发：

```javascript
temperature > 70℃
```

开启：

```javascript
sprinkler.enabled = true;
```

生成：

```text
水雾粒子
```

并降低火势：

```javascript
fire.level--;
```

# 9. 应急照明

火灾后：

```javascript
mainLight.enabled = false;
```

切换：

```javascript
EmergencyLight.enabled = true;
```

颜色：

```text
绿色
```

用于：

```text
疏散指示
安全出口
```
